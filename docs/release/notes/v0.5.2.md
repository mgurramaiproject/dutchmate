# DutchMate 0.5.2

This patch makes Firefox learning-history migration safer and recoverable where
older local records are still present.

## Fixed

- A local storage read failure no longer looks like an empty record.
- A failed migration does not replace the current learning record or mark the
  migration complete.
- Retained legacy saved-vocabulary and review-card data can restore missing
  items after an earlier incomplete migration.
- Existing learning progress is preserved while missing legacy data is added.

## Important limitation

This patch cannot restore data that Firefox already removed, including storage
cleared by an uninstall or data that was permanently overwritten before the
patch was installed.
