# DutchMate 0.6.0

This minor release adds the Practical Dutch supermarket learning path and a
compact, focused popup experience while preserving existing local learning
history across updates.

## Added

- Added the offline-first Practical Dutch supermarket topic with reviewed A1
  and A2 lessons, Dutch/English/Telugu support, practice, continuation, and
  intentional Keep behavior.
- Added compact topic rows, a focused Read/Notice/Practise/Keep flow, and
  browser-consistent narrow-popup layout using the existing design system.
- Added clearer public-facing Chrome, Firefox, and Edge-compatible Chromium
  release materials and listing state.

## Fixed

- Prevented Firefox local learning-history reads and migrations from treating a
  storage failure as an empty record.
- Preserved existing learning progress while recovering retained legacy saved
  vocabulary and review-card data after an incomplete migration.
- Kept failed migrations retryable without replacing the prior learning record.

## Changed

- Made upgrade-safe local learning history a default feature and release gate:
  saved items, lesson progress, mastery/evidence, rhythm, and applicable
  grammar, contrast, and Verb Journey progress must survive an update.
- Kept authored content bundled and offline-first; no account, cloud sync,
  runtime content translation, or new browser permission was added.

## Verification

- `corepack pnpm verify`
- `corepack pnpm verify:release`
- `git diff --check`
- Owner-confirmed Chromium and Firefox Feature 025 QA
- Installed-profile update check for existing learning history: required

## Notes

- This GitHub release packages Chrome, Firefox, and Edge-compatible Chromium
  artifacts; browser-store submissions remain separate manual actions.
- The release cannot recover learning data already deleted by a browser or
  permanently overwritten before the update.
