# DutchMate 0.5.0

This minor release turns DutchMate's reading companion into a clearer local
practice loop: read in context, keep useful words, and practise Dutch grammar,
verb forms, and sentences in short focused flows.

## Added

- Added grammar practice, sentence exercises, short Lessons, Daily Five, and
  Verb Journeys for `werken`, `zijn`, `hebben`, and `gaan`.
- Added English comparisons and multilingual form references across the verb
  learning experience.
- Added the typed, versioned content catalog that bundles reviewed Lessons,
  grammar, contrast, and Verb Journey packages without changing learner-history
  formats.
- Refreshed the public homepage with the current learner story, Chrome and
  Firefox listing links, and an honest Edge coming-soon state. Safari is
  intentionally deferred.

## Fixed

- Tightened store-ready host permissions while keeping local-testing access
  explicit and separate.
- Disabled hover translation in the Options page and kept selected-text
  translation visible when hover translation is off.
- Preserved existing Saved vocabulary, lesson progress, Verb Journey evidence,
  backups, and Daily Five behavior while adding the new practice content.

## Changed

- Kept learning data local to the browser with no account, subscription, or
  cloud sync.
- Published the current Chrome and Firefox packages plus the Edge-compatible
  Chromium package as GitHub Release assets; browser-store submissions remain
  a separate manual step.

## Verification

- `corepack pnpm verify`
- `corepack pnpm package:extensions`
- `node scripts/verify-extension-release.mjs`
- `git diff --check`

## Notes

- This GitHub release does not submit or update Chrome, Firefox, or Edge store
  listings. Safari is not included in this release target.
- The learning experience remains local and browser-based; the release makes
  no claim of proven language proficiency or learning transfer.
