# DutchMate 0.5.1

This patch release makes browser updates safer and keeps translation saves reliable.

## Fixed

- Migrate existing local learning data automatically when the extension updates.
- Keep the translation tooltip open while moving to its Save button.
- Preserve the previous learning record when a migration cannot complete.
- Remove the unused `downloads` permission from store manifests; browser-native
  backup exports remain unchanged.

## Browser packages

- Firefox, Chrome, and Edge-compatible Chromium packages were rebuilt from this release.
- Edge is approved and publicly available: https://microsoftedge.microsoft.com/addons/detail/dutchmate/plobaccfjjbpfekjomnmmidlmjjdecme
- Safari remains deferred.

## Verification

- `corepack pnpm verify`
- `corepack pnpm package:extensions`
- `node scripts/verify-extension-release.mjs`
- `git diff --check`

This GitHub release prepares store uploads; it does not submit to browser stores.
