# DutchMate 0.4.1

This patch release narrows the store-ready browser permissions for the Chrome
submission without changing DutchMate's passive hover and selection behavior.

## Fixed

- Removed wildcard HTTPS host permissions from store-ready manifests.
- Limited store-ready translation host access to the DutchMate backend.
- Kept localhost and wildcard HTTPS access available only in explicit local-testing builds.

## Verification

- `corepack pnpm test`
- `corepack pnpm typecheck`
- `corepack pnpm package:chrome`
- `node scripts/verify-extension-build.mjs chrome release/dutchmate-chrome-0.4.1.zip`

## Notes

- `activeTab` is not used because hover and selection translation must work without an extension-button click.
