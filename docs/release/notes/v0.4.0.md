# DutchMate 0.4.0

This minor release extends the local LearnLoop baseline with optional Context Missions, refined review and Saved workflows, and source-aware Dutch-English-Telugu reading support.

## Added

- Added optional Context Missions for deliberate webpage selections, including first-encounter reconstruction and saved-item recognition or recall without a popup tab.
- Added source-aware Dutch, English, and Telugu selection and hover behavior, including canonical Dutch saves, Seen-before matching, and no self-translation.
- Added provenance-aware Saved and review contexts with up to three recent contexts, helper translations, explicit unavailable states, and legacy-language handling.

## Fixed

- Fixed Context Slip lifecycle, keyboard/focus, positioning, failure recovery, and zero-provider-request boundaries across Chrome and Firefox.
- Fixed Saved and review recovery paths with Telugu phonetic helpers, Quiz Saved, lesson filters, focused-flow orientation, durable local activity, and preserved Daily Five behavior.

## Changed

- Kept learning data local to the browser, with no account, cloud sync, new permissions, or backend provider change.
- Kept Context Mission state ephemeral and the learning-effect claim experimental.
