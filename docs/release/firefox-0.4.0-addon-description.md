## Firefox addon page
- https://addons.mozilla.org/en-US/developers/addon/dutchmate/edit 

## Summary
Learn Dutch while browsing. Translate Dutch words or selected text into English or Telugu, save vocabulary, and practise with daily reviews and lessons. No account or subscription required.

## description
- Translate Dutch/English/Telugu words on any websites without switching tabs
- Build a personal Dutch vocabulary list from real websites
- English and Telugu translations with context support
- Review saved words with Daily Five practice and short lessons with flashcards
- Data stored locally in your browser
- No account, subscription, or payment required
