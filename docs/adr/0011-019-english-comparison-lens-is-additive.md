# Feature 019: English comparison lens is additive

Feature 019 adds an authored English comparison lens to the existing Verb
Journey packs as a versioned, presentation-only content evolution. The two
Dutch comparison roles remain distinct in the content contract, while stable
form identities, evidence, exports, and learner history stay compatible so a
presentation/content upgrade cannot silently reset or regrade a learner.

## Considered options

- Replace the existing twelve-form records in place: rejected because the new
  two-role multilingual contract and cue data would make compatibility and
  rollback ambiguous.
- Add a new parallel comparison system: rejected because it would duplicate
  content, rendering, and navigation inside the Verb Journey.
- Add the new fields under a new content version and reuse the existing pack
  and popup seams: accepted because it preserves the current learning model
  while making the new learner-facing distinction explicit.
