# Cross-language capture keeps the Dutch learning key

English and Telugu webpage selections use the same canonical Dutch learning item as Dutch selections, retaining source-language provenance, the exact selected-occurrence page context when it can be resolved safely, and available helper translations. Cross-language capture is limited to single words; ambiguous, multi-word, or otherwise non-canonical Dutch results remain translatable but do not expose Save until a future explicit disambiguation design exists. The safe-word boundary reuses the existing normalized Unicode letter/number plus apostrophe/hyphen eligibility rule rather than adding a dictionary heuristic. When the selected occurrence cannot be resolved, the word saves without context rather than retaining a misleading sentence. Source resolution trusts Telugu script in the selected text first, then supported nearest page metadata, then Dutch/English lexical evidence; a saved-form match can support `Seen before` but never overrides a confident source or invents one. Telugu hover never requests a Telugu self-translation: multi-target mode shows Dutch plus English, while one-target mode falls back to Dutch if Telugu is configured. Contexts preserve their source language, fixed English/Telugu renderings copy through when applicable, and each helper translation is independently best effort: a failed helper remains unavailable while the word saves, and later captures fill only missing helpers without overwriting existing translations. Legacy unknown-provenance contexts are never retroactively relabeled; an identical later context with known provenance remains separate. Learning backup format v2 remains additive and compatible: old v2 imports retain unknown provenance and new fields do not trigger a version bump. Saved shows up to three recent contexts per item, newest first, with each original language and helper rendering kept distinct. Encounter persistence records only bounded original context plus provenance; it does not trigger helper translation requests or hidden vocabulary enrichment. A unique saved Dutch, English, or Telugu form shows `Seen before` even without context; encounter persistence is attempted only when context exists, and ambiguous helper matches stay silent. Contextual recall and reconstruction remain Dutch-only. This preserves one Dutch mastery model, fixes the missing Telugu save path, and avoids quietly turning DutchMate into a multilingual learning mode.
