# Feature 016: `zijn` journeys use an additive multi-pack registry

Status: accepted

Feature 016 generalizes the Feature 015 single `werken` Verb Journey pack into
an additive multi-pack seam so `zijn` can be introduced without changing
existing `werken` identifiers, evidence, or learner history. Packs remain
versioned authored content selected by verb identity; they share the existing
deterministic practice, learning-record, Daily Five, and popup contracts rather
than creating a verb-specific framework. The package deliberately leaves
ambiguous Saved-to-`zijn` resolution and `zijn`-as-auxiliary teaching outside
this boundary until those concerns have a safe authored classification model.
