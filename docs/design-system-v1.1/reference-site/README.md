# Reference-site source

These files are the core React/CSS source behind the interactive DutchMate
design-system site:

https://dutchmate-design-system.spintothemoon.chatgpt.site

They are included so Codex can inspect exact component states, clickthrough
copy, layout rules, and responsive styling.

This folder is a visual/interaction reference, not a standalone application and
not a replacement architecture or replacement UI for the DutchMate browser
extension. Adapt the patterns to the extension’s existing framework and
preserve every existing control, section, heatmap, state, functional contract,
and storage contract unless a separate product change is explicitly approved.
Concepts shown only in this reference are future proposals, not automatic
additions during the first one-to-one visual retrofit.

The copy in `page.tsx` contains example learning content for reference only.
Production lessons and accepted answers require curriculum review.
