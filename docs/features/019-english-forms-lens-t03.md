# Feature 019 T03 — Complete `zijn` and `hebben` lens coverage

**Parent:** [Feature 019: English Forms Lens #153](https://github.com/mgurramaiproject/dutchmate/issues/153)
**GitHub issue:** [#156](https://github.com/mgurramaiproject/dutchmate/issues/156)

## What to build

Extend the shipped English comparison lens from `werken` to the remaining
active Verb Journey packs, `zijn` and `hebben`. Learners should receive the
same compact list, Dual-Dutch detail, cue behaviour, navigation, accessibility,
and preserved existing flows for all three verbs.

## Acceptance criteria

- [ ] `zijn` and `hebben` each provide twelve complete reviewed comparison
      records with two distinct Dutch roles, NL/EN/TE content, Dutch form
      identities, and authored cues.
- [ ] All three active packs render the same four-card period list, collapsed
      hierarchy, Everyday Dutch selection, cue display, and Dual-Dutch detail
      contract.
- [ ] Cross-pack validation proves twelve unique English forms, correct group
      counts, complete localized role records, valid badges, cues, stable
      identities, and the additive content version.
- [ ] Cross-pack popup tests prove entry from a journey and Dutch form, detail
      paging across period boundaries, restored list state, inline information,
      map navigation, and preserved practice actions.
- [ ] No comparison interaction creates or changes Verb skill evidence,
      mastery, scheduling, Daily Five state, or practice results.
- [ ] Focused tests, typecheck, build, and whitespace checks pass for the
      cross-pack release candidate.
