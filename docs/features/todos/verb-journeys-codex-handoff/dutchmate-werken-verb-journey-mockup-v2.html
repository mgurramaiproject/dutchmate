Werken 2 · NoticeVTT
Notice the pattern

The completed event

Compare a routine with a completed fact.

OTT
Ik werk meestal thuis.
routine / present situation
VTT
Ik heb gisteren thuis gewerkt.
completed conversational event
FORMULA
ik + heb + … + gewerkt

Use hebben with werken. The participle is gewerkt.

VALUABLE CONTRAST

Ik heb gisteren gewerkt is common when reporting one completed fact. Ik werkte vroeger thuis is common for past habits or story background.
